**QUESTION 1**

- confusion
Relationship between the key and the ciphertext should be as complex as possible to mittigate attacks.

- diffusion
Changing a single bit of plaintext then half of the bits in the ciphertext should change and same the other way, a small change, gives a big change in result.

- product cipher
Cryptosystem in which the encryption is formed by applying several sub-encryption functions.

- iterated cipher
Several round of same encryption method used to complicate. Sub encryption function are all the same function, called the round function Each key is derived from the master key K, the keys K-i are called round keys, you get K-i from K using a process called key schedule.

- Feistel cipher
A symmetric structure used in the construction of block ciphers. Also commonly known as a Feistel network.

- substitution-permutation network

- ECB mode
Electronic Code Block, a basic mode for block ciphers. Is deterministic so not normally used for bulk encyrption

- CBC mode
Cipher Block Chaining, chains the blocks together. Commonly used for bulk encryption, common choice for channel protetcion in all versions of TLS up to TLS 1.2

- CTR mode
Counter Mode, a synchronous stream cipher mode. Good for access to specific plaintext block without decrypting the whole stream. 

- true random number generator (TRNG)
Outputs each valid string independently with equal probability

- pseudorandom number generator (PRNG)
Each generator takes a seed as input and outputs a bit string before updating its state
