**QUESTION 1**

- collision resistance
Property of a hash function that it is computationally infeasable to find two colliding inputs. To satisfy collision resistance hash functions should have output of at least 256 bits.

- second preimage resistance
Related to collision resistance, where second preimage resistance is also known as weak collision resistance

- one-wayness
Given a value y it should be infeasable to find any input x with H(x) = y

- birthday paradox
In a group of 23 random chosen people, the probability that at least two have the same birthday is over 0.5. With a hash function H has an output size of k bits. If H is regarded as a random function then 2^k/2 trials are enough to find a collision with a probability around 0.5.
